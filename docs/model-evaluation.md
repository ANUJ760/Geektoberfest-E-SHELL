# Model evaluation report

Generated by `venv/bin/python evaluate.py --markdown docs/model-evaluation.md` on phrases the model was not trained on (`evaluation_phrases.json`, kept separate from `intents.json`).
Model: TF-IDF + LogisticRegression, trained on 273 phrases across 27 intents, confidence threshold 0.12. Environment: Python 3.13.5, scikit-learn 1.9.0.

## Summary

| Measure | Result |

| Supported requests understood | 95/135 = 70.4% |
| Supported requests answered with the **wrong command** | 8/135 = 5.9% |
| Supported requests not recognised (safe, but unhelpful) | 32/135 = 23.7% |
| Out-of-scope requests correctly refused | 15/15 = 100.0% |

With 150 phrases, one phrase moves the overall figure by 0.7 points, so treat small differences between runs as noise. Wrong commands are the costly mistake; not recognising a phrase only shows the help message.

## Effect of the confidence threshold

The model ranks intents by probability and E-SHELL only acts when the top probability is at least 0.12; otherwise it answers `unknown`.

| | Supported requests understood |
|---|---|
| Top-ranked intent, no threshold | 114/135 = 84.4% |
| With the threshold (what users get) | 95/135 = 70.4% |

| Average top probability | Value |
|---|---|
| Correct answers | 0.26 |
| Wrong commands | 0.17 |
| Not recognised | 0.09 |

These probabilities are small because the model splits its belief across 27 intents, and they are not calibrated: 0.30 does not mean a 30% chance of being right. Use them only to compare against the threshold, never as a measure of how sure the model is.

## Limits of this report

- The test phrases were written by hand for this project. They are a rough guide, not a sample of real users.
- Results come from the saved `.pkl` files, so retrain (`venv/bin/python train.py`) after changing `intents.json`, then re-run this report.
- `edit_file`, `make_executable` and `run_file` are only ever acted on through their exact typed forms (`edit x`, `make x executable`, `run x`), never because the model guessed them.
